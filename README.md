# HiveShard

HiveShard enables real-time data processing in high-performance clusters, automating scaling and load balancing for databases.

HiveShard is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/HiveShard.git`
2. `cd HiveShard`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure HiveShard, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
